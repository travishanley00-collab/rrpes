Deploys the way your infrastructure already works

No proprietary hosting, no vendor lock-in, no black box. Project Center 2.0 is a standard ASP.NET Core application your team owns end to end.

⌂

Flexible hosting

Runs on IIS on Windows Server, as a self-contained service on Linux, in a Docker container, or as an Azure App Service — same codebase, no rewrites between environments.

⛁

Standard, owned data

Backed by PostgreSQL or SQL Server. Your data lives in a normal relational database your team can query, back up, and report against directly — nothing hidden behind an API.

⇅

Schema-managed migrations

Every schema change ships as an EF Core migration. Roll forward with one command, review the generated SQL before it runs, and keep environments in lockstep.

◈

Role-based access

Estimators, PMs, shop floor, and leadership each see exactly what their role needs — access control lives in the platform, not in a spreadsheet's sharing settings.

▤

Audit trail by default

Activity logs, email logs, and change history are first-class data, not an afterthought — every meaningful action is attributable and reviewable after the fact.

▣

Zero-install access

It's a browser app. Office staff, shop crew, and installers reach the same real-time system from a desktop, tablet, or phone — no client software to image or patch.

Data integrity & security

Built so nothing gets silently out of sync

  • ✓

    Controlled reference data

    Lookup values like Building Type live in real, editable tables — renames migrate every affected record and log exactly what changed, with the ability to revert.

  • ✓

    Legacy data import

    Existing project records import directly from source JSON, with duplicate detection surfaced immediately instead of discovered downstream.

  • ✓

    Presence-aware editing

    Users see who else has a project open in real time, reducing the conflicting-edit problems shared spreadsheets are known for.

  • ✓

    Sandbox / training mode

    A one-click, fully-seeded throwaway database lets new hires and IT staff explore workflows without touching production data.
