What it does

Everything onboarding and review actually needs

Not a generic HRIS bolted on after the fact — a purpose-built onboarding, SOP, and review engine that already runs one real operation today.

DIR

Employee Directory

A searchable roster of everyone on the team, with bulk CSV import and export for updates and backups — not a spreadsheet only one person keeps current.

OB

Role-Based Onboarding Plans

Each new hire gets an onboarding plan for their role, built automatically from the SOP library instead of assembled by hand every time.

SOP

SOP Library

A governed library of standard operating procedures, each one flagged required or optional — the same source every onboarding plan and every review pulls from.

✓

Required Items Block Completion

Onboarding can't be marked done while a required SOP item is still open — so "finished" actually means finished, not just closed out of convenience.

REV

Review Cycles & Auto Due Dates

Set a review cycle once per person and the next-due date calculates itself from hire date going forward — reviews happen on schedule, not whenever someone remembers.

PTO

PTO Accrual & Balances

Vacation and sick time accrue against a real policy, with manual adjustments logged individually — a running balance, not a mental estimate.

REQ

Time-Off Requests

Employees submit time-off requests; a pending-count badge keeps managers from missing one, and every approval or denial is logged.

AUD

Shared Activity Log

Every add, edit, and approval writes to the same full audit trail as the rest of the platform — one history, not one per tool.

How it works

From "day one" to "on schedule, every cycle"

1

Add the employee

One at a time, or import a whole roster at once with the CSV importer — either way, they're in the same directory everyone else works from.

2

Assign an onboarding plan

Pick the role, and the plan populates itself from the SOP library — required items and optional items both, without retyping a checklist from memory.

3

Required items keep it honest

The plan won't mark itself complete while a required SOP item is still open, so onboarding status means what it says.

4

Reviews schedule themselves

Hire date plus review cycle produces the next-due date automatically — a review happens as often as it's set to, not just once a year if someone remembers.

5

Time off stays current

A request comes in, a manager approves or denies it, and the balance reflects it immediately — the same record everyone's looking at.

Why not just use a binder, or a separate HR system?

One more login is one more silo

A dedicated HRIS will do some of this too — but it's yet another system, another login, and another database that has no idea who's actually on a project right now.
